# Motor Winding Calculator

Standalone **Winding Scheme Calculator** (Bewicklungsrechner XL) for three-phase motor winding layouts.

Enter stator **slots**, **magnet poles**, and star/delta connection (**Y** / **D**) to get a winding scheme.

## Run locally

Open `index.html` (or `winding_calc.shtml`) in a browser, or serve the folder:

```bash
python -m http.server 8765
```

Then open http://127.0.0.1:8765/
